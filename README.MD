# FNOS 目录映射管理工具 (fnos-dir-manager)

这是一个专门为 **飞牛私有云 (FNOS)** 设计的自动化团队目录管理工具。它通过 Docker 容器运行，利用 Linux 的 `bind mount` 技术，实现团队公共目录到用户个人目录的动态映射，并自动初始化用户的个人文件夹。

在使用 FNOS 时，存在几个核心痛点：

1. 团队文件夹在手机客户端和网页客户端中，点击路径过长，需要多次跳转才能打开。
2. 在 SMB 共享中，如果没有事先在网页客户端中创建任何文件夹，则没有地方可以存私人文件。


## 🚀 核心功能

1.  **自动团队目录映射**：遍历 `/vol*/@team` 下的所有文件夹，将其自动挂载到 `/vol1/{UID}/@团队文件-{文件夹名}`，为避免与默认团队文件夹 smb 共享功能冲突，刻意添加@符号使其能够在SMB中隐藏，只显示官方的团队文件夹SMB。
2.  **个人文件夹初始化**：如果用户的个人存储池中不存在 `个人文件` 目录，工具会自动创建并修正权限（chown 为对应的 UID）。
3.  **动态清理**：当容器停止时，会自动卸载（umount）所有映射点并删除空的挂载目录，确保宿主机文件系统整洁。
4.  **安全保护**：采用 `rmdir` 指令删除挂载点，仅在目录为空（卸载成功）时生效，绝不触碰用户真实数据。

## 🧠 工作原理

该工具采用“容器化管理 + 宿主机穿透执行”的方案：
* **权限穿透**：容器通过 `privileged: true` 和 `pid: host` 模式运行，拥有操作宿主机内核挂载点的权限。
* **空间穿透**：利用 `nsenter` 命令进入宿主机的 Mount Namespace，使得容器内执行的 `mount` 命令直接作用于宿主机。
* **生命周期管理**：通过 Bash 的 `trap` 捕捉信号。当执行 `docker stop` 时，触发清理函数，确保挂载点被优雅卸载。

## ⚠️ 重要说明

* **UID 匹配**：本工具默认 `/vol1/` 下以纯数字命名的目录为用户目录。
* **权限继承**：`bind mount` 映射后的目录权限与源目录完全一致。请确保源目录（`@team` 下）的 Linux 权限已正确分配给相应的 UID。
* **卸载保护**：清理流程中严禁使用 `rm -rf`。如果某个目录因为文件占用导致卸载失败，`rmdir` 会因目录非空而报错跳过，从而保护底层数据安全。
